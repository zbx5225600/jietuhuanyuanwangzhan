## 快速命令参考

### 首次配置

```bash
# 一键配置
python setup_config.py

# 或手动配置
copy config.example.json config.json
notepad config.json
```

### 检查环境

```bash
python check_env.py
```

### 处理task

```bash
# 单个
python process_single.py task_0001

# 批量
python process_task.py
```

### 运行生成的项目

```bash
cd task_0001/output
npm install
npm run dev
```

## 配置优先级

```
┌─────────────────────┐
│  环境变量            │
│  OPENAI_API_KEY     │
└──────────┬──────────┘
           │
           │ 如果未设置
           ▼
┌─────────────────────┐
│  config.json        │
│  openai_api_key     │
└──────────┬──────────┘
           │
           │ 如果都未设置
           ▼
┌─────────────────────┐
│  报错提示            │
└─────────────────────┘
```

实际优先级: **config.json > 环境变量**

## 文件结构

```
项目根目录/
├── config.json              ← 你的配置 (不提交Git)
├── config.example.json      ← 配置模板
├── setup_config.py          ← 配置向导
├── check_env.py             ← 环境检查
├── process_single.py        ← 单任务处理
├── process_task.py          ← 批量处理
│
├── task_0001/               ← 示例task
│   ├── checkpoints/         ← 输入: 截图
│   ├── assets/              ← 输入: 资源
│   └── output/              ← 输出: Vue3项目
│
└── screenshot-to-code/      ← 核心代码
    └── backend/
        ├── routes/
        │   └── batch_process.py
        └── codegen/
            └── vue_extractor.py
```

## 常用命令速查

| 命令 | 说明 |
|------|------|
| `python setup_config.py` | 配置向导 |
| `python check_env.py` | 检查环境 |
| `python process_single.py task_0001` | 处理单个task |
| `python process_task.py` | 批量处理 |
| `cd task_0001/output && npm install && npm run dev` | 运行生成的项目 |

## Windows用户快捷方式

双击运行批处理文件：

- `setup_config.bat` - 配置向导
- `run_check.bat` - 环境检查
- `run_task_0001.bat` - 处理task_0001

## 故障排查

### 问题: API Key未找到

```bash
# 检查配置
python check_env.py

# 重新配置
python setup_config.py
```

### 问题: 依赖缺失

```bash
# 重新安装
pip install fastapi uvicorn openai python-dotenv aiofiles
```

### 问题: 生成的项目无法运行

```bash
cd task_0001/output
rm -rf node_modules
npm install
npm run dev
```
