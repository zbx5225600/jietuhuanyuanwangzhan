# 配置与模型

## 配置优先级

1. `config.json`
2. 环境变量

推荐使用 `config.json`，避免每次重设环境变量。

## 配置方式

### 方式 1：配置向导（推荐）

```bash
python setup_config_multi.py
```

### 方式 2：手动配置文件

```bash
copy config.example.json config.json
```

### 方式 3：环境变量

```powershell
$env:OPENAI_API_KEY="your-key"
```

## 关键参数说明

### `min_visual_similarity`

- 示例：`"min_visual_similarity": 0.9`
- 含义：页面视觉还原度阈值（0~1），`0.9` 表示目标还原度为 90%。
- 行为：若某页面还原度低于阈值，会进入下一轮修复（在重试次数允许范围内）。
- 建议：通常使用 `0.85~0.92`，默认推荐 `0.9`。

### `max_restore_attempts`

- 示例：`"max_restore_attempts": 5`
- 含义：最大复原循环次数，防止死循环。
- 行为：最多尝试 5 次；到上限仍未达标则停止，并输出当前结果与还原度报告。
- 建议：默认 `5` 即可。

## 示例配置片段

```json
{
  "provider": "openai",
  "model": "gpt-4-vision-preview",
  "min_visual_similarity": 0.9,
  "max_restore_attempts": 5
}
```

## 模型支持说明

- 国际模型：OpenAI
- 国产模型：通义千问、豆包、文心、智谱（以 `setup_config_multi.py` 支持项为准）

## 安全建议

- 不要提交真实 `config.json`
- 不要在日志中打印完整 API Key
- 确认 `.gitignore` 已包含敏感配置文件
