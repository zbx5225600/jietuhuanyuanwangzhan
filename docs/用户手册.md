# 用户手册

## 1. 环境准备

- Python 3.10+
- Node.js 18+
- 可用的模型 API Key（OpenAI 或国产模型）

先执行：

```bash
python check_env.py
```

## 2. 配置

推荐使用交互式配置：

```bash
python setup_config_multi.py
```

也可手动复制并编辑：

```bash
copy config.example.json config.json
```

建议在 `config.json` 增加：

```json
"min_visual_similarity": 0.9,
"max_restore_attempts": 5
```

说明：
- `min_visual_similarity=0.9`：页面还原度目标 90%。
- `max_restore_attempts=5`：最多复原 5 次，防止死循环。

## 3. 处理任务

单任务：

```bash
python process_single.py task_0001
```

批量：

```bash
python process_task.py
```

## 4. 运行生成结果

```bash
cd task_0001/output
npm install
npm run dev
```

访问 `http://localhost:5173`。

## 5. 结果输出

任务结束时会输出：
- 每个页面还原度（百分比）
- 整体还原度（平均值）

如果没有 `compare/gen_step_*.png` 对比图，会显示 `N/A`。
