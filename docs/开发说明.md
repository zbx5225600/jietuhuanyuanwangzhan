# 开发说明

## 项目定位

该项目在 `screenshot-to-code` 基础上扩展了面向任务目录的处理流程，核心目标是把截图还原为 Vue3 + Vite 工程。

## 关键代码位置

- 后端路由：`screenshot-to-code/backend/routes/`
- 代码提取：`screenshot-to-code/backend/codegen/`
- 提示词与策略：`screenshot-to-code/backend/prompts/`
- 前端界面：`screenshot-to-code/frontend/src/`
- 本地任务处理脚本：根目录 `process_single.py`、`process_task.py`

## 主要流程

1. 读取 `task_xxxx/checkpoints` 截图
2. 构造提示并调用模型
3. 解析模型输出为项目文件
4. 复制 `assets` 并写入 `output`
5. 在 `output` 中运行前端项目

## 测试说明

- 集成流程测试：`tests/test_batch_process.py`
- 提取器测试：`tests/test_extraction.py`
- 路由修复验证：`tests/test_route_fix.py`
- checkpoint 路由生成测试：`tests/test_checkpoint_routes.py`

## 二次开发建议

- 新增模型时优先复用现有 provider 结构
- 提示词修改集中在 `prompts` 目录，避免逻辑分散
- 先补测试，再改核心流程
